01 / MANIFESTO 我们为什么用「跃迁」二字

没有过渡。之前是一种存在，
之后是另一种存在。

跃迁在物理学中描述的是粒子在能级之间的非连续性状变。不是渐进的移动，而是消失在 A、出现在 B。这种不连续性、不可逆性，是衔远与数十个宣称"向前迈进"的企业 AI 品牌区分开来的核心。

01 · NOT
跃迁≠转型

转型有路径、有起点、有可回头的修正。跃迁没有路径——能量积聚到临界，状态切换在那一刻完成。

02 · NOT
跃迁≠升级

升级是版本号的累加。跃迁是基础态的整体置换，无法通过累加抵达，只能通过临界。

03 · NOT
跃迁≠进化

进化是连续优化。跃迁是 Context 跨过阈值进入 Weight——从软记忆变成硬能力，是不可逆的硬切换。

WHY NOT L3

为什么 L3 大模型厂商不做 L4？

智谱 / DeepSeek / Kimi / MiniMax 战略是通用模型，不愿为每个行业建仿真环境（ROI 不划算）。大厂平台（千帆 / 百炼）做通用工具层 L5，做不了行业深度。

唯一例外：代码方向（Codex / Claude Code）= L3 自营 L7，但只做超大规模垂直。

WHY NOT L5 / L6

为什么 L5 / L6 做不了 L4？

Dify / Coze / LangGraph（L5）= Agent 编排工具，不训练模型。滴普 / 商汤 / 第四范式（L6）= 数据治理 + 项目交付，不自研 RL 算法和行业环境。

两者都缺：RL 全栈算法 · 行业仿真环境 · 通专融合架构 —— 三者叠加才构成 L4。

L4 = 用 RL 训练行业专业模型 + 构建通专协同架构　以上调 API 做编排，以下提供通用能力；中间唯一空白即是 Frontis 的占位。

04 / META-ENGINE 自进化引擎

MetaAgent × Bootcamp
制造 AI 的 AI

核心不是交付单个 Agent，而是掌握批量制造高质量 Agent 的元能力 —— 从「授人以鱼」到「授人以渔」。两种交付节奏 · 双重进化循环。

MODE · 01 FAST

快模式

分钟级交付

基于已积累的构建经验，直接组装最优 Agent 配置（Skill 组合 + 协作策略 + 记忆方案）。供应链客户积累的经验，分钟级迁移到下一个供应链客户。

核心：经验复用 —— 检索最相似场景，基于已有最优模式组装微调，跨客户、跨行业经验迁移。

MODE · 02 DEEP

慢模式

天级深度训练

调用 Bootcamp 对高价值场景进行深度训练。传统人工构建需 3–6 个月，Bootcamp 压缩至天级。

① 环境合成：行业数据自动合成训练场景
② 奖励建模：专家判断标准编码为可微分奖励
③ 强化学习：GRPO 驱动策略迭代，试错内化为直觉

SKILL EVOLUTION · 内循环

SkillAgent 精进

Work Agent 在 Bootcamp 中通过五阶段生产线持续精进 —— 业务执行的每条轨迹、专家修正的每个信号都被转化为进化的训练数据。反馈来自客户专家标注、专家预测对比、测试集验证、实际业务回测 —— 所有效果提升都有客观可量化的验证。

META-COGNITION · 外循环

多场景构建经验反向优化 MetaAgent 的元认知。三类经验积累：任务拆解模式 · Skill 组合策略 · RL 训练超参。构建的 Agent 越多，制造精度越高 —— 网络效应，不是线性积累。
