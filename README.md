## 设计理念

整站围绕**「让临界可见」**展开 —— 一道 `#00C1D4` 跃迁青线横贯页面，将每一屏切分为「之前·密度」和「之后·开阔」两种状态。

- 量子黑 / 跃迁青 / 纯白 / 余能灰 / 能级灰 / 能量橙 六色系统
- 无渐变 · 无投影 · 无圆角 · 无对称居中
- cubic-bezier(0.16, 1, 0.3, 1) 跃迁曲线驱动所有动效
- 单文件 · 零外部依赖（仅 Google Fonts）
